- **[Labstep](https://www.labstep.com/)** — A powerful web-tool helping scientists be more creative
- **[Plumed](https://plumed.org/)** — An extension to molecular dynamics codes for running enhanced sampling simulations ([contributions](https://github.com/plumed/plumed2/commits?author=jandom))
- **[Ligandbook](https://ligandbook.org/)** — A public repository for OPLS-AA ligand parameters
- **[Lipidbook](https://lipidbook.org/)** — Older brother to ligandbook
- **[MDAnalysis](https://www.mdanalysis.org/)** — A top-notch MD data analysis library ([contributions](https://github.com/MDAnalysis/mdanalysis/commits?author=jandom))
